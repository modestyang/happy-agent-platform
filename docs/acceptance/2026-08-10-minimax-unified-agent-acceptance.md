## 验收中已修复

1. 新增 MiniMax Provider 和 MiniMax M3，并把四类 AI 能力统一到 `fitness.coach` 的已发布版本。
2. 清理 MiniMax `<think>` 内容，避免出现在普通回复、结构化解析和 Trace 输出中。
3. 为报告、三餐和图片识别增加明确 JSON 字段约束、输出上限和 fenced JSON 兼容，同时保留服务端严格校验。
4. 修正本地 profile 未启用本地媒体存储的问题，恢复完整图片识别链路。

## 修改建议

### P1：补齐新用户三餐生成入口

“今天还没有饮食建议”页面只有说明文字。建议增加“立即生成”按钮，调用现有 daily meal plan generate operation；生成中显示进度，失败后原位提供重试。个人应用做到这一条即可，不需要任务中心或复杂调度后台。

### P2：稳定 AI 回复排版

MiniMax 偶发返回不完整 Markdown，页面会露出裸 `*`。建议让健身对话优先返回纯文本，或在渲染前做轻量 Markdown 规范化；不要引入富文本编辑器。

### P2：降低 Trace 使用门槛

Trace 首页要求管理员手工输入用户 UUID。建议默认展示最近会话，或提供用户名下拉选择。个人应用不需要高级查询平台。
