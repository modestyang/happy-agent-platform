# V1 功能冻结清单

本清单中的“合同已冻结”表示产品行为和 HTTP DTO 已在 OpenAPI 固定；不表示业务实现已完成。后续任务不得在合同外自行增加端点或改变语义。

## 手机端 `/app/**`

- [x] 首页固定 2×2：目标、训练、饮食、身体。
- [x] 首页聚合当前目标、今日训练、今日三餐、最近身体指标和 AI 花爷入口。
- [x] 偏好读取与乐观更新：时区、单位、饮食限制、器械、训练日/时长、语音与提醒。
- [x] 目标列表、创建、详情、更新和激活；同时最多一个当前目标。
- [x] 当前目标累计报告；无当前目标、排队、生成、就绪、陈旧、失败语义闭合，并可异步刷新/重试。
- [x] 客观身体、饮食、训练记录不保存 `goalId`，报告按当前目标时间窗聚合。
- [x] 训练计划列表/详情、计划动作详情、动作替换和版本冲突保护。
- [x] 跟练固定 UI、结构化语音提示和实际训练记录。
- [x] 动作库筛选、分页和动作详情/媒体。
- [x] 每天用户时区 05:30 生成早餐、午餐、晚餐计划并支持恢复任务。
- [x] 三餐计划反馈：采纳、跳过、份量变化、评分和说明。
- [x] OSS 上传票据、图片识别异步任务、状态查询和可编辑候选。
- [x] 手工饮食记录及历史分页；识别结果需确认后才成为记录。
- [x] 身体指标手工记录及历史分页。
- [x] 训练记录手工/跟练完成写入及历史分页。
- [x] AI 花爷 24 小时固定期限会话、消息、异步 Run 和 SSE 游标续传。
- [x] AI 输出使用闭合结构化组件，不允许任意 HTML。

- [x] Framework 目录与详情：代码登记、只读能力和兼容性。
- [x] Provider 目录、创建/更新、掩码凭据、轮换、健康与能力探测。
- [x] Model 目录、创建/更新、能力字段和异步探测。
- [x] Tool 目录/详情：完整输入输出契约、风险、安全上限、版本和引用影响；核心只读。
- [x] Skill 创建、编辑、复制、预览、版本差异、发布和影响；仅 Markdown/元数据/只读资源/授权 Tool。
- [x] Hook 目录/详情：阶段、顺序、超时、失败策略、必选和兼容性；核心只读。
- [x] Memory Policy 独立版本目录与创建。
- [x] Prompt 独立版本目录与创建。
- [x] Output Schema 独立版本目录与创建。
- [x] Evaluation Suite 独立版本目录与创建。
- [x] 所有组件公共生命周期、兼容性、引用和停用影响。
- [x] 默认配置档案列表、创建、版本详情和乐观更新。
- [x] 四层默认继承、稀疏覆盖、恢复默认、来源展示和最终配置解析。
- [x] Agent 列表、创建、详情和唯一工作草稿。
- [x] 草稿乐观更新、兼容性校验和解析后完整配置预览。
- [x] 异步评测任务、用例结果和安全门。
- [x] 发布不可变版本，冻结所有组件版本、默认档案、有效配置与 checksum。
- [x] 回滚通过创建新发布版本实现，不修改历史快照。
- [x] 会话列表/详情、Run 列表/详情、Trace 事件和敏感数据脱敏。
- [x] Playground 异步 Run 与可续传 SSE。

## 平台合同规则

- [x] 两份 OpenAPI 均为 3.1.0，全部对象 Schema 闭合，禁止空对象和任意 map。
- [x] 每个写请求要求 `Idempotency-Key`。
- [x] 每个乐观写要求 `If-Match`，并定义 `412` 与 `428`。
- [x] 每个异步创建返回 `202` 与 `Location`。
- [x] 全部错误使用 Problem Details 和闭合错误码，至少包含 `DEPENDENCY_NOT_CONFIGURED`、`CURRENT_GOAL_NOT_FOUND`、`SAFETY_GATE_FAILED`、`FRAMEWORK_NOT_SUPPORTED`。
- [x] SSE 支持 `Last-Event-ID`，事件类型和 payload 闭合。
- [x] 前端类型由合同脚本确定性生成，可用 `git diff --exit-code` 验证复现。

## 明确非目标

- [x] 不接运动手表、支付、社交或医疗诊断。
- [x] 不允许模型生成任意 HTML。
- [x] 不允许 Skill 执行任意 Java、Python 或 Shell。
- [x] 不引入 Redis、消息队列、微服务、Kubernetes、生产告警或自动备份。
- [x] 不提供历史目标独立报告，不把客观记录强绑单一目标。
