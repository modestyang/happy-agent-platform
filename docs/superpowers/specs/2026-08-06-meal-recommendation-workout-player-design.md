# 今日饮食推荐与沉浸式跟练设计

## 目标与边界

本次只修改正式项目 `/Users/modest/IdeaProjects/happy-agent-platform`。`/Users/modest/IdeaProjects/fitness` 继续作为只读视觉参考。

本次解决五项体验问题：

1. 首页饮食卡从饮食记录入口改为下一餐推荐入口。
2. 首页四张功能卡消除标题与图标重叠，并展示训练、饮食的有效摘要。
3. 计划动作卡扩大图片、压缩无效留白并保持图片比例。
4. 周日历压缩星期和日期的垂直间距。
5. 新增独立沉浸式跟练页，按照动作、组数、休息状态连续计时和语音播报，结束后调用真实训练完成 API。

不在本次范围内：接入尚未完成的 Agent Runtime、通过 AI 实时生成饮食建议、视频课程素材生产。饮食建议使用正式数据库模型；本地环境通过数据库种子初始化可验收数据，未来 Agent 直接写入同一张表和同一 API 契约。

## 方案选择

采用独立页面方案：饮食进入 `/meal/today`，跟练进入 `/workout/:planId`。

- 相比抽屉，饮食页能容纳三餐、下一餐状态和生成缺失状态。
- 相比计划页原地计时，独立跟练页能隔离导航、滚动和训练状态，避免误触离开。
- 暂不采用视频课程引擎；当前动作库是图片指导模式，播放器优先显示正式图片，种子文字占位图继续由本地姿势 SVG 兜底。

## 今日饮食推荐

新增数据库表 `daily_meal_recommendations`：

- `recommendation_id`
- `user_id`
- `recommendation_date`
- `meal_type`：`BREAKFAST`、`LUNCH`、`DINNER`
- `items`：结构化食物名称与预估热量
- `reason`
- `status`：`READY`、`GENERATING`、`FAILED`
- `generated_at`
- 同一用户、日期、餐次唯一

Bootstrap 增加 `mealRecommendations`。首页按用户本地时间选择“下一餐”：9 点前早餐、12 点前午餐、18 点前晚餐；18 点后仍展示晚餐并标记“今晚”。卡片展示餐次、首要食物名称、总预估热量。无当天推荐时展示“今日建议尚未生成”，点击进入饮食页的明确空状态，不伪造推荐。

今日饮食页展示三餐纵向卡片并高亮下一餐。每餐展示食物、合计热量与推荐理由；页面保留返回按钮，不加入底部主导航。饮食记录继续只从首页“记录”进入。

## 首页与计划排版

首页四宫格保持暖色调。每张卡片采用三段结构：顶部独立图标徽章、中部标题、底部摘要；箭头固定在右下角，任何字号下都不覆盖标题。

- 训练：计划主题；“预计分钟 · 动作数 · 总组数”。
- 饮食：下一餐标签；推荐食物；“约 kcal”。
- 记录：身体与饮食记录提示。
- 报告：当前目标累计分析提示。

计划页日期按钮缩短内部间距并减小星期与日期的 `gap`。动作卡使用左右布局，图片区域占约 42%，设置稳定 `aspect-ratio` 和 `object-fit: cover`；信息区域占约 58%，动作步骤以紧凑序号排列，不留下大块空白。窄于 360px 时仍保持两列，但适当减少间距。

## 跟练状态机

新增 `WorkoutPlayer`，以明确状态驱动页面与语音：

1. `READY`：展示训练概览，用户点击开始后获得浏览器语音授权。
2. `COUNTDOWN`：3 秒准备倒计时，播报“训练准备，3、2、1”。
3. `EXERCISE`：展示当前动作、当前组/总组、剩余秒数；进入时播报动作名、组数和第一条要点；最后 3 秒逐秒播报。
4. `REST`：同一动作组间休息 20 秒，动作之间休息 30 秒；播报休息时长和下一个动作。
5. `PAUSED`：冻结计时，继续后从剩余秒数恢复。
6. `COMPLETED`：只调用一次 `POST /api/app/workouts/{id}/complete`，成功后展示总时长、完成动作数，并刷新 Bootstrap。

播放器提供暂停/继续、上一个、下一个、静音和退出。跳过动作会进入下一个动作或完成态；退出训练需要二次确认。切换动作前取消未完成的语音，避免播报叠加。组件卸载时清理 interval 和 speech synthesis。

跟练页视觉采用深色沉浸背景承托暖珊瑚色进度，主动作图居中放大。顶部仅保留退出、总进度和静音；中部是动作图、动作名称与要点；底部是大号倒计时和控制按钮，并预告下一动作。

## 数据与错误处理

- 饮食推荐、计划、动作全部来自 Bootstrap/数据库，不在前端创建业务推荐假数据。
- 推荐查询失败沿用全局加载错误；当天无推荐使用空状态。
- 浏览器不支持语音时计时照常运行，并显示文字提示。
- 训练完成 API 失败时保留完成页面和重试按钮，不把失败状态伪装成已打卡。
- 重复点击完成不会重复提交。
