# 健身应用字体收敛设计

## 目标

将手机端从偏手写、偏玩具感的字体表达调整为轻松现代的圆润无衬线风格。页面仍然温暖、有亲和力，但标题、数字和操作文案应更清晰、耐看，适合长期使用。

## 范围

- 仅调整健身应用手机端字体栈、标题字重和少量字距。
- 不调整颜色、圆角、阴影、布局、功能或 Agent 管理工作台。
- 不引入网络字体，避免国内部署时出现外部字体加载失败、闪烁和额外请求。

## 字体体系

- 全局正文：`Avenir Next`、`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`、系统无衬线字体。
- 标题与强调：`Avenir Next`、`PingFang SC`、`Hiragino Sans GB`、系统无衬线字体。
- 移除 `Hannotate SC`、`Yuanti SC` 等手写或卡通感明显的字体。
- 标题主要使用 700 字重，关键数字可保留 800；普通按钮与标签从 800–900 收敛至 700。
- 标题负字距减弱，避免字形挤压产生夸张的可爱感。

## 验收标准

- 首页、计划、跟练、瘦瘦、动作库和我的页面不再渲染手写字体。
- 页面层级仍通过字号、字重和色彩区分，不依赖卡通字体。
- 原有布局不发生溢出、换行或高度回归。
- 前端测试、类型检查、Lint 与生产构建通过，并在手机宽度浏览器检查首页、计划页与跟练页。
