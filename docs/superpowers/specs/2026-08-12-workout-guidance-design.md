# 训练动作指导、计时与本机语音设计

## 目标

在不改变数据库、后端接口和动作数据结构的前提下，修复计划页与训练播放器的多图展示、准备倒计时语音积压问题，并增加逐秒节拍音和本机语音风格选择。

## 设计

### 动作图片

- `ExerciseVisual` 保留现有单张图片、SVG 兜底和可展开查看行为。
- 计划卡片与训练预览在存在多张图时每 1500ms 自动切换一帧，并展示简洁分页点。
- 用户启用减少动态效果时不自动切换，计划卡片可通过分页点手动查看。
- 正式训练由训练状态的已进行秒数控制图片帧，按 `1→2→…→N→…→2` 往返播放，避免末帧直接跳回首帧。

### 训练计时

- 活跃阶段使用一次性 1000ms timeout 推进状态；每次状态变化后重新注册下一次推进。
- 暂停、退出、完成或组件卸载时清除未触发的 timeout。
- 该策略保证一个倒计时数字至少完整展示一秒，不允许重复 interval 造成同一秒内多次推进。

### 语音与节拍

- 普通播报继续使用 FIFO，确保动作名称、暂停和完成信息不被吞掉。
- 倒计时提示标记为时效提示；新的时效提示到达时，删除尚未播放的旧倒计时，当前数字过期后不得补播。
- 准备阶段只播报 `3、2、1`，不再把较长的“训练准备”与数字放在同一句中。
- 训练和休息期间每次秒数变化播放短促节拍；最后 3 秒使用更高、更明显的音色。节拍由 Web Audio 振荡器生成，不增加音频资源与依赖。
- 静音同时作用于语音和节拍；暂停、跳过、退出和卸载会停止对应声音资源。

### 本机语音预设

- 提供 `系统默认`、`温柔女声`、`磁性男声` 三个预设。
- 预设组合设备中文语音、语速与音调。优先匹配常见系统音色名称；没有匹配时选择任一中文音色，再降级为系统默认。
- 页面不承诺跨设备音色完全一致，选择入口显示在训练预览页。
- 选择保存在浏览器 `localStorage`，仅影响当前设备，不新增服务端字段。

## 异常与降级

- 无 Web Speech 时保留屏幕计时与节拍音，并显示已有的不支持提示。
- 无 Web Audio 时语音与计时继续工作，节拍引擎安全空操作。
- 图片加载失败或仍是种子占位图时继续使用现有姿态 SVG。
- 语音列表异步加载时，每次播报前重新读取可用声音，不阻塞训练开始。

## 验收

- 计划页多图动作能自动轮播；减少动态效果时可手动换图。
- 训练中同一组动作图片会随秒数往返变化。
- 准备阶段 `3、2、1` 不积压、不连读，每个屏幕数字至少存在一秒。
- 训练与休息中间每秒有节拍，最后 3 秒提示更明显；静音和暂停后无节拍。
- 三种语音预设可选择并在刷新后保留；缺少目标音色时不报错。
